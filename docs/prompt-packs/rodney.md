# Rodney prompt pack

Built-in Grok Imagine prompts for Rodney. Studio reads the machine file
`rodney.json` next to this document. Each set below is a **complete**
prompt: the style block plus the sheet instructions.

Other characters get their own pack later by copying this shape: a
`styleBlock` string plus `sets[]` with a complete `prompt` that includes
`{{styleBlock}}` and `{{name}}`.

Do **not** ask for slanted eyes or any mocking ethnic eye gesture in any
set. A "squint" means ordinary lids lowered, same eye shape as the rest
of the pack.
