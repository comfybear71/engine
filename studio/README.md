# Studio (coming later)

This folder is a placeholder for the future Studio app: a Next.js app
(deployed on Vercel) that writes scripts and edits `timeline.json`.

It is out of scope for this PR. The render worker (`worker/`) and the
`timeline.json` schema (`schema/timeline.schema.json`,
`docs/timeline-schema.md`) are the stable contract the Studio will target
once it exists -- see the root [README.md](../README.md) for the overall
architecture.
