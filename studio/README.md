# Studio

Local Next.js app (App Router) for editing `script.txt` and viewing
`timeline.json`. It reads and writes files **only** through the worker
Express server on the user's machine (`127.0.0.1`, default port 4100).

There is no Vercel Blob, database, or auth in this first slice.

How to run both sides on Windows: **[docs/studio.md](../docs/studio.md)**.
